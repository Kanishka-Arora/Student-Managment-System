Recommended Firestore Security Rules

In the Firebase Console under Firestore Database > Rules, apply the rules defined in firestore.rules: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Only authenticated administrative users can read and write student data
    match /students/{studentId} {
      allow read, write: if request.auth != null;
    }
  }
}
